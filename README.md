# Projetos Sobre Criptografia

## RailNere (Rail Fence + Vigenere) // EM DESENVOLVIMENTO

Esse projeto envolve projetar e desenvolver uma cifra nova, criada através da junção de uma cifra de substituição e uma de transposição. Após a implementação do cifrador e do descifrador, um conjunto de testes foi realizado a fim de gerar um relatório comparativo da cifra implementada com os algoritmos de criptografia AES e RSA implementados na OpenSSL.

### RailNere/src/

Contém implementações do cifrador/decifrador de RailNere, junto de outros códigos utilizados para geração do relatório, como a execução dos testes, plot dos resultados e extração de métricas como tempo e memória dos algoritmos.
